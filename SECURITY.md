# Security Policy

## Supported versions

Sayo is pre-1.0. Security fixes target the latest development version.

## Reporting a vulnerability

Do not disclose vulnerability details in a public Issue. Report them privately through
[GitHub Security Advisories](https://github.com/sugipamo/sayo/security/advisories/new). If private vulnerability
reporting is unavailable, open an Issue without sensitive details and ask how to contact a maintainer privately.

Include the impact, reproduction steps, affected version, and any known workaround. Maintainers will confirm receipt,
attempt to reproduce the issue, and discuss the response privately.
